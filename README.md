# memorycard
Memory Card (Quiz App)

Memory Card — это простое приложение-викторина на Python с использованием PyQt5.
Пользователь видит вопрос и 4 варианта ответа, выбирает один и нажимает кнопку «Ответить».
После этого показывается результат: правильный ответ или нет, и можно перейти к следующему вопросу.

🧠 Функциональность

Отображение вопроса и 4 вариантов ответов

Проверка правильности ответа

Показ результата

Переход к следующему вопросу

Счетчик вопросов и правильных ответов
